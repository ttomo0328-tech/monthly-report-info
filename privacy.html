プライバシーポリシー

更新日：2026年10月19日

本ポリシーは、管理者本人が利用するMacアプリ「月次報告」と、このアプリの案内サイトに適用します。

1. 取り扱う情報と目的

利用者が指定する請求書Excelに含まれる顧客名、対象月、施術日、施術料などの情報を、実績の集計、手数料計算、報告本文と請求書PDFの作成に使います。

利用者が設定した宛先、宛名、定型文、署名と、生成したPDFを、Gmail下書きの作成に使います。Googleからは、接続に必要な認証情報と、作成した下書きの識別情報を取得します。

2. Googleアカウントへのアクセス

接続にはGoogleのOAuth認証を使用します。アプリがGoogleアカウントのパスワードを取得・保存することはありません。

要求する権限は gmail.compose です。Googleの確認画面では「下書きの管理とメールの送信」と表示されます。このアプリが行うのは下書き作成までであり、受信メールを読む処理やメールを送信する処理は実装していません。

Googleから受け取った情報の利用・転送は、Google API Services User Data PolicyのLimited Use要件を含む規定に従います。

3. Mac内の処理とGoogleへの送信

Excelの読み取り・集計・PDF作成はMac内で行います。Gmailとの認証・認証更新時にはGoogleと通信します。下書き作成時には、メールの宛先・件名・本文・添付PDFをGoogleのGmail APIへ送ります。

管理者が用意した外部サーバーへ、顧客データや認証トークンを送信する仕組みはありません。顧客データを広告、販売、外部AIの学習・推論には利用しません。

4. 保存場所と削除

情報ごとの保存先
認証トークン利用者のMacのキーチェーンに保存します。
設定・作成履歴利用者のMac内に保存します。下書きの重複作成を防ぐため、作成結果の履歴を保持します。
請求書PDF利用者が選んだMac内の保存先に保存し、利用者が管理・削除します。
Gmail下書き接続したGoogleアカウントのGmailに保存します。利用者がGmailで確認・削除できます。

読み込み時に作るExcelの一時コピーは、次のファイルの読み込み成功時またはアプリの通常終了時に削除します。異常終了時には残る場合があります。元のExcelは変更しません。

Googleアカウントの接続管理から、アプリへのアクセス許可を解除できます。許可の解除だけでは、Macに保存したPDF・設定・作成履歴や、Gmailに作成済みの下書きは削除されません。それぞれの保存先で利用者が削除します。

5. この案内サイトについて

このサイトには、利用登録、請求書のアップロード、アクセス解析ツール、広告の機能を設けていません。

サイトの公開に使用するGitHub Pagesでは、セキュリティ目的で閲覧者のIPアドレスが記録されます。詳しくはGitHubのプライバシーステートメントをご確認ください。アプリの請求書データやGoogle認証情報を、このサイトの公開用リポジトリへ保存しません。
